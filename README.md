# 智慧宿舍回寝系统

智慧宿舍回寝系统是一个专为学校宿舍管理设计的Web应用，帮助学校管理宿舍回寝情况，进行数据统计和预警。

## 主要功能

- **账号系统**: 支持管理员、主任、班主任、导育老师和学生多种角色
- **宿舍管理**: 宿舍信息管理、学生分配
- **班级管理**: 班级信息管理、学生分配、班主任分配
- **回寝检查**: 导育老师可以进行宿舍回寝检查，记录学生回寝情况
- **统计分析**: 提供各类回寝统计数据和可视化图表
- **请假管理**: 学生请假审批流程
- **留堂记录**: 记录学生留堂情况

## 新增功能

### 1. 检查时段管理

- 支持设置两个回寝检查时段(如晚自习和晚寝)
- 管理员可以在设置页面配置时段名称、开始时间、结束时间和预警时间
- 系统根据当前时间自动识别活跃时段

### 2. 归档功能

- 检查时段结束后自动将该时段的检查记录归档
- 归档后的数据仍可查看但不能修改
- 新时段开始时，所有学生状态重置为未归寝

### 3. 预警通知

- 到达预警时间点自动向主任和班主任发送预警通知
- 通知提醒查看学生回寝情况
- 用户可在顶部导航栏查看所有通知

### 4. 通知系统

- 支持系统通知、预警通知和信息通知三种类型
- 通知状态管理(已读/未读)
- 通知中心显示所有通知历史

## 技术栈

- **前端**: Next.js, React, TailwindCSS
- **后端**: Next.js API Routes
- **数据库**: PostgreSQL
- **ORM**: Prisma
- **认证**: NextAuth.js

## 部署要求

- Node.js 16+
- PostgreSQL 12+

## 开发设置

1. 克隆仓库
```bash
git clone <repository-url>
cd smart-dorm-system
```

2. 安装依赖
```bash
npm install
```

3. 配置环境变量，创建`.env`文件:
```
DATABASE_URL="postgresql://username:password@localhost:5432/dbname"
NEXTAUTH_URL="http://localhost:3000"
NEXTAUTH_SECRET="your-secret-key"
```

4. 运行数据库迁移
```bash
npx prisma migrate dev
```

5. 启动开发服务器
```bash
npm run dev
```

## 系统设置

管理员可以通过"系统设置"页面配置以下内容:

1. 检查时段设置
   - 时段名称(如"晚自习"、"晚寝")
   - 时段开始和结束时间
   - 预警时间点

2. 归档设置
   - 归档后的数据保存期限
   - 是否自动归档

## 定时任务

系统通过API路由`/api/cron/check-periods`实现自动化任务:

- 自动检查时段状态并归档过期时段
- 在预警时间点发送通知
- 建议通过外部cron服务每5分钟调用一次

## 定时任务配置

为了启用学生未回寝提醒功能，需要设置以下定时任务：

### 1. 检查未回寝学生并发送通知

这个任务每10分钟检查一次未回寝且未被留堂的学生，如果超过预警时间，将向班主任和主任发送通知。

```bash
# 使用 crontab（Linux/Unix/macOS）
# 每10分钟执行一次
*/10 * * * * curl "https://你的网站域名/api/cron/schedule?task=check-not-returned"
```

### 2. 检查回寝时段

这个任务用于检查时段的状态，发送预警通知和标记归档。

```bash
# 使用 crontab（Linux/Unix/macOS）
# 每5分钟执行一次
*/5 * * * * curl "https://你的网站域名/api/cron/schedule?task=check-periods"
```

如果使用Windows服务器，可以使用Windows任务计划程序设置类似的定时任务。

## 消息通知配置

学生未回寝通知功能依赖于WxPusher配置。请确保：

1. 已正确设置WxPusher的appToken
2. 相关用户（班主任和主任）已绑定了WxPusher
